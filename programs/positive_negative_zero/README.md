# Positive Negative Zero

This directory contains the C++ source code for the **Positive Negative Zero** program.

## Goal
Check whether a number is positive, negative, or zero.

## Step-by-Step Execution
1. Declares integer variable `num`.
2. Asks the user to enter a number.
3. Evaluates using an `if-else` chain:
   - If `num > 0`, outputs "Positive".
   - Else if `num < 0`, outputs "Negative".
   - Otherwise, outputs "Zero".
4. Returns `0`.

## Code Reference
- [main.cpp](main.cpp)

## How to Compile & Run
To compile and run this program, follow these instructions:

### Prerequisites
Make sure you have a C++ compiler (like `g++`) installed on your system.

### 1. Compile the Program
Navigate to this directory in your terminal and compile the program:
```bash
g++ main.cpp -o main
```

### 2. Run the Executable
- **Windows:**
  ```powershell
  ./main
  ```
- **Linux / macOS:**
  ```bash
  ./main
  ```
